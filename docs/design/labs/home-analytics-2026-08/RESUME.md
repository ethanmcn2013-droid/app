## The method as run here

- Seats are generated by `panel-round.mjs --mode=prompts`, then driven as
  parallel subagents, one per seat prompt. Append the environment note
  (Playwright's location, the scratchpad, `?motion=play`) to each prompt.
- Findings are **clustered before refutation** in `panel/clusters-round-N.json`
  — same defect seen by several seats becomes one claim, every alias kept.
  One fresh refuter per cluster, via `panel/make-refuters.mjs round-N`.
- A refuter that returns `real: false` **but affirms the problem and supplies
  a sharpenedFix** is recorded as confirmed carrying the refuter's fix. Pass
  those ids to `record-round.mjs --replaced=`. The alternative — a real,
  correctly-classed defect dying because the seat's wording did not fit a
  pill — would let the engagement close over defects nobody disputes.
- Assertions are authored in `panel/round-N-batchM-assertions.js` with an
  editor tool and spliced by `panel/append-assertions.mjs` — never through a
  heredoc, which ate four escapes in a previous engagement.
- Fixes are applied by `panel/fix-*.py`, exact string replacement, no regex.

Worth more than the defects that exposed them, and both now fixed:

1. Round 1's `the unfinished week is hatched, open-topped` assertion measured

   certified the opposite of the protected contract it guarded.
2. Round 1's `every control acknowledges a press` grepped `document.styleSheets`

   geometry assertions built both DOMs from the same fixture in the same frame
   and compared them to each other, so they could not fail.

Both classes are now asserted from rendered state. When adding assertions,
the test is: **would this fail if the thing it guards were broken?**

A full visual re-exploration of the signed-in Tasks product, and of the black L-shaped chrome around it. How this was made

    

      The reference frames are the shipped app in review mode, captured at 390×844,
      768×1024, 1280×900 and 1440×960, the four breakpoints the experience registry
      already names. The loading frames are the real ones, held still: the harness serves
      the page's own streamed shell rather than mocking a skeleton.
    

    

      The directions are pixel-real HTML artboards driven by the same fixture data and set
      in the real Geist, using the vendored design-system tokens unedited. Every proposed
      token change is additive and named in its own file. The dense state is the one
      extension: the shipped fixture holds a single project, so peak season is written out
      using the two other couples the fixture already names.
    

    

      Exploration only. Local branch design/tasks-exploration, no pull
      request, no deploy. The chrome and navigation contract gates are knowingly not
      satisfied by any of this; they get updated at lock-in, once Tasks, Notes and
      Timeline are all decided.

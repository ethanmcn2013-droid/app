Seat: evidence

Problem: The nine-step space ladder is declared under a twelve-line comment naming the defect it fixed ("it drifted to twenty-six distinct values"). audit.mjs enforces it by grepping `margin|padding` in the built .css files only, so margins and paddings are almost fully tokenised and the enforcement stops there. The actual spacing mechanism on this surface is `gap` on flex and grid, and it is untouched: 26 gap declarations across b.css and shell.css, exactly one of which uses a token (`gap: var(--gap-tight)`), carrying twelve distinct values — 6, 8, 10, 12, 14, 16, 18, 28, 32, 48, 56, 64 — of which seven (6, 10, 14, 18, 32, 48, 64) are not steps on the ladder. `gap: 10px` alone appears nine times. Below that sits a second unreadable layer: render-b.js writes spacing as inline style strings (`gap:6px` x3, `margin:0 0 10px -5px`, `margin-bottom:8px`, `margin-bottom:12px`, `margin:26px 0 0`, `margin-top:26px`, `margin-top:14px`), which the source check cannot see at all because it reads .css files.

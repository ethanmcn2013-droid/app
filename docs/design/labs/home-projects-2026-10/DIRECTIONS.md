# Home and Projects · directions · October 2026

Design exploration only. All directions render inside the real Next App and its existing shell. The same fictional account, task facts, dates and explicit unknowns are supplied by one typed review adapter. Real authorisation and Project identities are not expanded.

## The shared job
Home brings useful attention into focus. Projects makes the work understandable and reachable. Every direction preserves personal tasks, Project context, meaningful next dates, incomplete data and empty/loading/error states. Clicking task or Project content opens a clearly read-only local detail; it never reports a saved change. Review controls preserve URLs, drafts, keyboard focus and a downloadable founder preference.

## A · The Brief
Thesis: a considered daily brief with one next decision, followed by clear personal and team work. Projects is a deliberate directory rather than a dashboard.
Sacrifice: fewer details at once; a frequent operator may prefer more persistent context.
Standing decisions: sidebar and navigation identity retained; the current Home composition is replaced only inside the explicit review branch.
Materials: existing semantic v3 tokens and Geist. No global palette change.
Delight: a useful task opens with its Project and next date already connected; dismissing it returns to the original place.

## B · The Workbench
Thesis: keep the work and its context side by side. A task or Project selection changes a persistent detail area instead of making the operator repeatedly open and close panels.
Sacrifice: denser and less quiet than A; phone layouts must deliberately collapse the workspace.
Standing decisions: keeps Project identity and the actual App shell; does not introduce another task runtime.
Materials: existing semantic tokens and current type families; structure carries the difference.
Delight: move between items while keeping the surrounding work visible.

## C · The Horizon
Thesis: see today's work in relation to actual upcoming dates. Projects becomes a sequence of meaningful next moments, with a real place for undated work.
Sacrifice: less natural for date-light work; its undated lane must be as usable as the calendar.
Standing decisions: does not replace Timeline or imply computed dependencies or forecasting.
Materials: existing semantic tokens, typographic dates and precise linework, no new brand palette.
Delight: a next date leads directly to the relevant local Project/task context.

## Review zones
1. Entry and first useful action.
2. Task hierarchy and context.
3. Project comparison and unknown information.
4. Detail, navigation and return.
5. Phone readability, keyboard focus and state recovery.

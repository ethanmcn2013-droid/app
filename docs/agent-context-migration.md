## Claude compatibility

The local @AGENTS.md adapter loads at the repository root, but the tested Claude Code 2.1.236 and 2.1.287 default modes did not expand it when launched inside src. The qualified setup uses Claude Code 2.1.287 with Project instructions set to claude-md-and-agents-md. This user-level setting directly loads AGENTS.md and deduplicates an already imported file. A project-local setting is not honored for this option. Configure it in the user's settings, a supported --settings profile, or managed policy; do not solve it with a Windows symlink or copies of the full rules in every folder.

Actual ordinary-session tests with the adopted user setting identified the nine core instruction meanings from both root and src. Codex 0.152.1 also passed both locations. The failed default-mode experiments remain evidence; successful process exit alone did not qualify loading. Other versions, cloud review, and another machine require their own loading check. Existing running Claude sessions were not restarted by the local stable-channel update.

Official behavior and settings: https://code.claude.com/docs/en/memory#choose-which-instruction-files-load

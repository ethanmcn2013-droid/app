# Chat and workspace navigation

This guide describes the selected sprint candidate. Check the release record before treating it as available in production.

## Chat without leaving your page

Choose the circular message icon at the bottom right. Open a project conversation or your private conversation labelled with your name and “you”. Close the panel to return to the page; navigating elsewhere keeps the current draft in this signed-in browser session. On phones the panel opens as a sheet.

Personal chat is private to the signed-in account. Choose Export Markdown to download that conversation, including message times. A successful send is confirmed by the server; a local review preview explicitly labels its messages as temporary. The preview does not prove saved production messages.

Where supported, the microphone button asks for permission before starting dictation. Review the text and choose Send yourself. Browser speech services may process audio according to the notice shown before use. If speech is unavailable, typing remains available.

The conversation menu can hide a conversation from your list. Restore hidden conversations from the list controls. Hiding is a personal browser preference; it does not delete the conversation or archive its project.

## Organise the sidebar

Home, Analytics and Files stay at the top. Workspace contains Projects, Tasks and Timeline. Collapse a section using its heading. Each hub has a separate control for its tool list.

More contains Development and the Wedding, Teacher and Student hubs. Automations is under Development; Whiteboard is under Teacher. Tools marked Coming soon are previews, not completed features. Wedding opens the eligible project chooser and the existing guest-list journey.

Choose Customize More to show or hide entries, or restore defaults. These choices are saved in this browser. Enabling a child reveals its parent. The choices change navigation, never access rights.

Project rows offer a visible more button and a matching right-click menu. Open the project, Tasks, Timeline or Files, or copy its link. Ordinary text fields retain their browser editing menu.

## Settings and Files

Opening Settings from a page shows a floating card. Close it or use Escape to return. Unsaved changes require a dismissal decision. Direct Settings links still work.

Files groups the selected project's existing files by task. Open a folder to browse that task's files; use All files to return. Selecting a file preserves the preview on larger screens. This view does not create a second storage system or change attachment permissions.

## Readable links

Message links show a readable site and path while keeping the original destination. Supported project links can include a project-name hint alongside the stable identifier. Renaming a project does not change the identifier or grant access. Existing shared links and links carrying necessary view or planning context remain supported.

Signal Studio · Google Drive boundary

One board folder is shared. The parent stays private.

The app requests the exact drive.file scope, creates a private organising root, and grants named access only on the selected board folder. This is an explanatory model, not a release-status report.

Three walls protect the rest of a person's Drive

A folder grant never exposes its parent or a sibling board. Someone who is also a member of another board may hold a separate exact grant for that board; this grant does not provide it.

Wall 1 · Google limits the token

The exact drive.file scope reaches only files Signal Studio created or that a user explicitly opened with it. No full-Drive, read-only-Drive, or identity scope is requested.

Wall 2 · The parent stays private

The organising root is never shared. A board member cannot move upward from the board folder into the parent.

Wall 3 · Grants are exact

Each current non-owner member receives named writer access on one board folder. “Anyone” and domain-wide grants are forbidden; sibling access requires its own grant.
